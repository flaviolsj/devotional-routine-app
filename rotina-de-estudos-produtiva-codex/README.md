# Rotina de Estudos Produtiva

Projeto Vite + React + Tailwind CSS v4, pronto para abrir no Codex IDE/CLI/App.

## Como abrir no Codex

Segundo a documentação oficial da OpenAI, o jeito mais direto é abrir a pasta do projeto no Codex IDE extension/CLI, ou conectar o repositório GitHub no Codex web. O Codex IDE extension trabalha diretamente no diretório do projeto, e o Codex web usa repositórios conectados ao GitHub. citeturn644291search1turn644291search2turn644291search12
